# SelfSubmit email signature

One signature for:

- `reminders@selfsubmit.co.uk`
- `ullah-noor@selfsubmit.co.uk`
- `support@selfsubmit.co.uk`

Open `selfsubmit-signature.html` in Chrome, copy the white card, and paste it into each mailbox. The From line already shows which address sent the email, so the signature does not repeat an email address.

The official HMRC mark is at the bottom (image only). Do not describe it as approved, certified, or kitemarked. The permitted wording is **Recognised by HMRC**.
